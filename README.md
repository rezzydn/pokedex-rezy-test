# Pokedex

A cross-platform Pokedex — **desktop web, mobile web, and native iOS/Android** — built with **Angular (standalone components)**, **Ionic 8**, and **Capacitor 6**. Pokemon data comes live from [PokeAPI](https://pokeapi.co/).

## Features

- Infinite scroll browsing through every Pokemon
- Detailed Pokemon view — types, height/weight, abilities, description, base stats
- Official artwork on cards and detail pages
- Favorites with toast confirmation and on-device persistence
- Type filter (Water, Grass, Fire, Ghost, Flying, ...) combinable with name search
- Pull-to-refresh and loading/error/empty states

## Prerequisites

- Node.js 18+ and npm
- For native builds: Xcode 15+ (iOS) and/or Android Studio (Android)

## How to run

### 1. Install dependencies

```bash
npm install
```

### 2. Run on desktop / mobile web

```bash
npm start
```

Opens on `http://localhost:8100`. The layout is responsive — resize the browser or open it on a phone to see the mobile web view; it's the same build for both.

### 3. Run as a native iOS / Android app (Capacitor)

```bash
npm run build:prod       # build the Angular app into www/
npx cap add ios          # first time only
npx cap add android      # first time only
npm run cap:sync         # copy www/ into the native projects + update plugins
npm run cap:open:ios     # opens Xcode
npm run cap:open:android # opens Android Studio
```

From Xcode or Android Studio, run on a simulator/emulator or a real device as normal. Re-run `npm run cap:sync` any time you change web code and want it reflected natively.

> The `ios/` and `android/` folders are generated by `npx cap add` and aren't committed (see `.gitignore`) — they're reproducible from `capacitor.config.ts` and the web build.

### 4. Production build only (no native step)

```bash
npm run build:prod
```

Output goes to `www/`.

## Data source

Pokemon data and artwork are fetched at runtime from PokeAPI's public REST endpoints (`https://pokeapi.co/api/v2/...`) and its sprite CDN. No API key is required.
